# Изображения

`zerno.jpg` и `barbershop.jpg` — превью проектов для секции «Работы».

Сейчас это **автоматические скриншоты** живых сайтов (1200×750, 16:10).
Можете заменить их своими — просто положите файлы с теми же именами:

- `images/zerno.jpg` — превью кофейни «Зерно»
- `images/barbershop.jpg` — превью барбершопа «ТОПОР»

Рекомендации: соотношение **16:10** (напр. 1200×750 или 1600×1000),
формат JPG, вес до ~150 КБ. Пути в коде уже относительные (`images/...`).

Третью карточку можно добавить копипастой блока `.project` в
`index.html` — сетка `auto-fit` сама разложит.
