# Портфолио Daniil — страницу собирают курсоры

https://bestedaniil.github.io/portfolio/

При первом открытии вкладки на тёмный экран вылетают цветные курсоры с ролями — «вёрстка», «анимация»,
«текст», «цвет», «картинки», «тесты» — и собирают страницу, как в редакторе макетов: рамки блоков с размерами,
посимвольная печать, заливка акцентов, проявление превью. Курсор «тесты» пробегает по готовым блокам и ставит
зелёные галочки. Нижние секции собираются, когда до них долистали. Внизу рой из сотен маленьких курсоров
перетекает из слов «ДЛЯ ВАС» в сердце и обратно.

Чистый HTML/CSS/JS на ES-модулях, без библиотек и сборки. Шрифт Inter лежит в `fonts/` —
ни Google Fonts, ни других внешних сервисов. Хостинг — GitHub Pages.

## Как это устроено

- **Весь контент лежит в HTML сразу.** Анимация — только слой поверх. Прятать блоки может только JS
  (класс `assembling` на `<html>` ставит скрипт в `<head>`), поэтому без JS и для поисковиков страница полная.
- **Любая клавиша** (кроме R и S) или клик мышью мгновенно показывают готовую страницу. Прокрутка
  сборку не прерывает: листаешь — секции собираются по мере появления; касание пальцем тоже не пропускает.
- **R** — собрать ещё раз, **S** — медленно (в три раза).
- **Не анимируется:** при `prefers-reduced-motion` (рой — статичное слово) и при повторном визите в той же вкладке
  (`sessionStorage`); R запускает вручную.
- **Телефон:** 8 курсоров сборки вместо 18, сборка короче; в рое 150 курсоров вместо 420.
- **Первый экран** собирается не дольше 5 секунд (хореография — 4,5 с, это проверяет тест). Финальный вид пиксель в пиксель совпадает со статичной версией
  (это проверяет тест).
- **Рой** — `<canvas>`: иконка курсора рисуется один раз и копируется `drawImage`, учитывается `devicePixelRatio`.
  Кадры идут, только когда рой виден и вкладка активна — вне экрана ноль работы.

```
js/
  content.js    ВЕСЬ ТЕКСТ САЙТА — правится здесь
  render.js     content.js → разметка (чистая функция)
  timeline.js   хореография: шаги { курсор, действие, элемент, старт, длительность }   ┐ чистые модули
  shapes.js     формы роя: точки слова, сердца, сопоставление без перелётов           │ без DOM,
  easing.js     плавность движения                                                    │ тесты в Node
  random.js     детерминированный генератор случайных чисел                           ┘
  assemble.js   проигрывание сборки: курсоры, рамки, печать, галочки
  swarm.js      рой на canvas
  app.js        точка входа: подпись, рой, сборка, клавиши R и S
tools/content.mjs   npm run content — переписывает index.html из content.js
```

## Как поменять текст

1. Откройте `js/content.js` и поправьте строки в кавычках.
2. Выполните `npm run content` — `index.html` обновится (страница должна быть полной и без JS).
3. `npm test` проверит, что `index.html` совпадает с `content.js`.
4. Поменяли CSS или JS — поднимите `?v=N` в `index.html`: у `style.css`, `app.js` и у всех модулей в `importmap`.

## Тесты

```bash
npm install          # один раз: Playwright (только для разработки, в браузер не попадает)
npm test             # node --test: хореография, формы роя, сопоставление, easing, контент
npm run e2e          # Playwright в установленном Chrome: 11 проверок из ТЗ и ещё несколько
npm run mutate       # поломки чистых модулей — юнит-тесты обязаны покраснеть
npm run mutate -- --e2e   # поломки интерфейса — браузерные тесты обязаны покраснеть
BASE_URL=https://bestedaniil.github.io/portfolio/ npm run e2e   # то же по живому сайту
```
